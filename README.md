# Prototipo de página principal — Constructora

Abrir `index.html` con Live Server de VS Code. Sitio HTML/CSS/JS sin framework.

## Decisiones
- Manrope para títulos, Inter para cuerpo.
- Carbón, naranja, oliva y blanco cálido.
- Contenido comercial y nombre **provisionales**.
- Imágenes de referencia cargadas externamente desde Unsplash: reemplazarlas por fotografías autorizadas del cliente antes de publicar.
- El formulario está deshabilitado intencionalmente hasta recibir WhatsApp oficial y aviso de privacidad definitivo.
- El banner guarda una preferencia local demostrativa; **no constituye una implementación completa de Google Consent Mode v2**.
- No hay etiquetas Google Ads ni GA4 instaladas, ni conversiones configuradas.
- Las tarjetas de servicios enlazan temporalmente a contacto; crear las seis landing pages en la siguiente fase.
- No publicar las páginas legales provisionales como políticas definitivas.

## Pendiente antes de producción
Nombre comercial, logo, teléfono, email, cobertura, fotografías y autorización de uso, dominio, textos legales validados, landing pages por servicio, SEO y medición real.


## Adaptación VIGO
Identidad visual y contenido inicial ajustados según referencias compartidas. El logo PNG se extrajo de una captura y debe sustituirse por el archivo oficial cuando esté disponible. El formulario permanece deshabilitado y las páginas de servicios aún están pendientes.
